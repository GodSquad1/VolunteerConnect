# VolunteerConnect 🌎🤝

VolunteerConnect is a lightweight MVP web app that helps users discover local volunteer opportunities, match with organizations based on their interests and availability, and manage outreach through a clean modern interface. Users can sign in, complete a short onboarding questionnaire, view recommended organizations, RSVP to upcoming volunteer events, and send outreach messages — all within a responsive frontend prototype.

Built using HTML, Vanilla JavaScript, Tailwind CSS, and Firebase Authentication, this project focuses on rapid UX prototyping and interactive flows rather than backend infrastructure. The app uses mock JSON data and localStorage to simulate a real-world volunteer matching platform while keeping the stack simple and beginner-friendly.
